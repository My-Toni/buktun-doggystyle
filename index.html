Cara Top Up Diamond

1

Pilih Game dan Paket Diamond

Pilih game yang ingin Anda top up (Free Fire, Mobile Legends, dll) kemudian pilih paket diamond yang sesuai dengan kebutuhan Anda. Klik tombol "Beli Sekarang" pada paket yang dipilih.

2

Lengkapi Data Checkout

Isi form checkout dengan data akun game Anda (User ID/Nickname, Server) dan pilih metode pembayaran yang diinginkan.

3

Kirim ke WhatsApp

Klik tombol "Checkout via WhatsApp" untuk mengirim pesanan Anda ke admin kami via WhatsApp. Pastikan data yang tertera sudah benar.

4

Lakukan Pembayaran

Admin akan mengirimkan nomor rekening atau metode pembayaran yang tersedia. Lakukan pembayaran sesuai nominal yang tertera dan kirim bukti transfer ke admin.

5

Konfirmasi dan Proses Top Up

Setelah pembayaran dikonfirmasi, admin akan memproses top up diamond ke akun game Anda. Proses biasanya memakan waktu 1-5 menit setelah konfirmasi pembayaran.

6

Diamond Masuk ke Akun

Cek akun game Anda untuk memastikan diamond sudah masuk. Jika dalam 10 menit diamond belum masuk, segera hubungi admin via WhatsApp untuk konfirmasi.

Penting Diperhatikan:

  • Pastikan User ID dan Server yang Anda berikan sudah benar
  • Simpan bukti pembayaran sampai diamond masuk ke akun
  • Jangan berikan password akun game kepada siapapun
  • Proses top up hanya bisa dibatalkan sebelum pembayaran dilakukan
  • Untuk masalah teknis, hubungi WhatsApp kami di jam operasional 08:00 - 22:00 WIB
